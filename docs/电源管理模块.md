# 电源管理模块

## 1. 功能

当前电源管理模块实现了：

- 通过 `I2C` 读取 `IP5306-I2C` 充电状态三态
- 通过 `SAADC` 读取电池电压
- 按 `3300mV -> 0%`、`4200mV -> 100%` 线性换算电量
- 按 `10%` 档位四舍五入
- 主控侧通过 `keep_alive_event` 保活
- 每 `8s` 通过 `P0.22` 对 `IP5306 KEY` 发送一次低电平短脉冲保活

## 2. 硬件连接

- `IP5306 SDA` -> `P1.0`
- `IP5306 SCL` -> `P0.24`
- `IP5306 KEY` -> `P0.22`
- `BAT_ADC_EN` -> `P0.09`
- `BAT_ADC` -> `P0.31`

分压网络：

- `R6 = 100k`
- `R8 = 100k`

所以：

- `BAT_ADC = VBAT / 2`
- 实际电池电压 `VBAT = ADC测得电压 * 2`

## 3. 状态判定

依据手册寄存器：

- `0x70 bit3 = 1` -> 充电开启
- `0x71 bit3 = 1` -> 已充满

三态映射：

- `0x71 bit3 = 1` -> `已充满`
- 否则 `0x70 bit3 = 1` -> `充电中`
- 否则 -> `未充电`

## 4. 电量换算

换算规则：

- `3300mV -> 0%`
- `4200mV -> 100%`
- 中间线性插值
- 最终按 `10%` 档位四舍五入

示例：

- `3300mV` -> `0%`
- `3350mV` -> `10%`
- `3740mV` -> `50%`
- `4200mV` -> `100%`

## 5. 保活机制

### 主控保活

模块正常工作时发送：

- `keep_alive_event`

### IP5306 保活

模块会：

- 初始化时把 `0x02 bit[3:2]` 设置为 `64s` 轻载关机时间
- 每 `8s` 通过 `P0.22` 发送一次 `100ms` 低电平短按脉冲
- `BAT_ADC_EN` 使能后等待 `10ms`
- 丢弃第一次 ADC 采样，第二次作为有效值

## 7. RTT 验证

启动预期：

```text
ip5306 ready: i2c=0x75 key=P0.22(active low) bat_adc_en=P0.09 bat_adc=P0.31
ip5306 sys_ctl2: old=0x.. keepalive_pulse=100ms period=8000ms poll=1000ms bat_adc_en_active=1
keyboard app ready
```

状态变化时预期：

```text
battery status=充电中 voltage=4012mV level=80% reg70=0x08 reg71=0x00
```

保活脉冲预期：

```text
ip5306 keepalive pulse
```
