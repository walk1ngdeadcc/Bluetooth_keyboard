# 模式切换模块

## 1. 功能

当前模式切换模块基于 `SAADC` 检测 `MODE(P0.29)` 节点电压，实现三模识别：

- `USB`
- `2.4G`
- `BLE`

当前版本：

- 每 `500ms` 采样一次
- 只在模式切换时打印
- 预留后续扩展接口，不直接切换业务模式

## 2. 硬件

- `MODE` -> `P0.29`
- ADC 通道：`AIN5`

阈值规则：

- `< 825mV` -> `USB`
- `825mV ~ 2475mV` -> `2.4G`
- `>= 2475mV` -> `BLE`

## 3. 软件策略

为避免拨码边界抖动，当前模块使用：

- `40us acquisition-time`
- `oversampling = 4`
- 连续 `2` 次采样一致才确认切换

```text
mode switch ready: adc=P0.29(AIN5) interval=500ms usb<825mV 2.4G<2475mV ble>=2475mV
```

```text
mode switch: USB, voltage=412mV
mode switch: 2.4G, voltage=1630mV
mode switch: BLE, voltage=3012mV
```
