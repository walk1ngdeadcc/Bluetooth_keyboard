# 按键唤醒

## 1. 方案概述

当前按键唤醒模块使用 Nordic 官方 `CAF` 方案实现：

- `CAF buttons`：负责矩阵按键扫描
- `CAF power_manager`：负责超时进入低功耗
- `CAF buttons_pm_keep_alive`：按键按下时自动喂活系统，避免正常使用中误休眠

本次验证使用“挂起态”而不是 `system off`：

- 5 秒无操作后进入低功耗
- 按下任意按键后退出低功耗
- 通过 RTT 打印进入和退出低功耗日志

## 4. 低功耗行为

当前配置为：

- `CAF power_manager` 在系统空闲 5 秒后触发 `power_down_event`
- `CAF buttons` 收到低功耗事件后切到按键唤醒待机状态
- 按下任意按键后，`CAF buttons` 触发 `wake_up_event`
- 应用收到 `wake_up_event` 后恢复正常工作

为了方便控制台验证，当前启用了：

```conf
CONFIG_CAF_POWER_MANAGER_STAY_ON=y
```

这意味着系统只进入挂起态，不会真正 `sys_poweroff()`。

## 5. 验证日志

验证时需要看 RTT 输出。

预期现象：

1. 上电后正常启动
2. 5 秒内不按键，打印：

```text
进入低功耗
```

3. 再按任意一个按键，打印：

```text
退出低功耗
```

## 6. 待机时间设置位置

进入待机时间现在在 [prj.conf](</D:/code/SGGProject/Bluetooth_keyboard/prj.conf:18>) 里设置：

```conf
CONFIG_CAF_POWER_MANAGER_TIMEOUT=5
```

单位是秒。

如果后面你想改成 10 秒，就改成：

```conf
CONFIG_CAF_POWER_MANAGER_TIMEOUT=10
```
