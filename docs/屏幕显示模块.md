# 屏幕显示模块

## 1. 功能

当前屏幕模块负责显示：

- 电量百分比
- 充电状态
- 当前模式：`USB` / `2.4G` / `BLE`

模块实现文件：

- [src/display_module.c](</D:/code/SGGProject/Bluetooth_keyboard/src/display_module.c:1>)
- [src/display_module.h](</D:/code/SGGProject/Bluetooth_keyboard/src/display_module.h:1>)

## 2. 使用的官方模块

显示链路没有自定义底层驱动，直接复用了 Zephyr 官方模块：

- `zephyr,mipi-dbi-spi`
  - SPI 四线 DBI 接口
- `sitronix,st7789v`
  - ST7789V 屏幕控制器驱动
- `display` API
  - 统一显示接口
- `pwm` API
  - 背光亮度控制

## 3. 硬件参数

当前工程接入参数如下：

- 分辨率：`320 x 172`
- SPI 总线：`spi3`
- `SCK`：`P1.13`
- `MOSI`：`P0.28`
- `CS`：`P0.02`
- `DC`：`P0.03`
- `RESET`：`P1.10`
- 背光：`PWM0 CH0 -> P1.11`
- 背光配置：`PWM_USEC(50)`，即约 `20 kHz`
- 背光极性：`PWM_POLARITY_INVERTED`
- `Y offset`：`34`
- 上电等待：`120 ms`

## 4. 屏幕方向

当前屏幕按横屏使用，方向参数为：

- `mdac = <0xa0>`

这个值对应当前板子的横屏方向修正，避免出现横屏但上下颠倒的问题。

## 5. 刷新方式

当前实现采用条带刷新：

- 颜色格式：`RGB565`
- 分条高度：`24` 像素
- 刷新周期：`1000 ms`

这样做的目的是降低一次性缓冲区占用，不影响其他功能模块。

## 6. 电源行为

屏幕模块会响应 CAF 电源事件：

- 收到 `power_down_event`：
  - 关闭背光
  - 打开 blanking
- 收到 `wake_up_event`：
  - 重新刷新界面
  - 恢复背光
