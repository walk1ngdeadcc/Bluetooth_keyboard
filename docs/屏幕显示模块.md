# 屏幕显示模块

## 1. 功能概述

当前屏幕模块实现的是一个横屏三栏界面：

- 左侧：电池图标 + 电量百分比
- 中间：
  - 充电中 / 已充满时显示状态图形
  - 未充电时显示内置图片资源
- 右侧：只显示 `USB` 和 `BLE` 两个模式卡片

## 2. 使用的官方模块

显示底层仍然直接复用 Zephyr 官方模块，没有额外自定义底层驱动：

- `zephyr,mipi-dbi-spi`
  - SPI 四线 DBI 接口
- `sitronix,st7789v`
  - ST7789V 屏幕控制器驱动
- `display` API
  - 统一显示接口
- `pwm` API
  - 背光亮度控制

## 3. 硬件参数

当前工程接入参数如下：

- 分辨率：`320 x 172`
- SPI 总线：`spi3`
- `SCK`：`P1.13`
- `MOSI`：`P0.28`
- `CS`：`P0.02`
- `DC`：`P0.03`
- `RESET`：`P1.10`
- 背光：`PWM0 CH0 -> P1.11`
- 背光配置：`PWM_USEC(50)`，约 `20 kHz`
- 背光极性：`PWM_POLARITY_INVERTED`
- `Y offset`：`34`
- 上电等待：`120 ms`

## 4. 屏幕方向

当前屏幕按横屏使用，方向参数为：

- `mdac = <0xa0>`

这个值用于修正横屏时的上下颠倒问题。

## 5. 刷新方式

当前实现继续采用条带刷新，避免一次性申请整屏缓冲：

- 颜色格式：`RGB565`
- 分条高度：`24` 像素
- 刷新周期：`1000 ms`

这样可以尽量不影响键盘现有功能模块。

## 6. 状态来源

屏幕显示的数据来自现有模块的只读状态：

- 电池有效位 / 充电中 / 已充满 / 电量百分比
  - [src/power_module.c](</D:/code/SGGProject/Bluetooth_keyboard/src/power_module.c:375>)
- 当前实际传输模式
  - [src/transport_manager.c](</D:/code/SGGProject/Bluetooth_keyboard/src/transport_manager.c:87>)
- USB 使能 / VBUS / 枚举就绪
  - [src/usb_hid_module.c](</D:/code/SGGProject/Bluetooth_keyboard/src/usb_hid_module.c:425>)
- BLE 使能 / advertising / connected
  - [src/ble_hid_module.c](</D:/code/SGGProject/Bluetooth_keyboard/src/ble_hid_module.c:751>)

右侧模式卡片的显示规则：

- 高亮当前实际模式：`USB` 或 `BLE`
- USB 圆点：
  - 已就绪显示绿色
  - 插着线但未就绪显示蓝色
  - 其他情况显示灰色
- BLE 圆点：
  - 已连接显示绿色
  - 正在广播显示绿色系高亮
  - 其他情况显示灰色或弱化

说明：

- `2.4G` 功能底层没有被删除，只是按当前使用习惯不在屏幕上显示

## 7. 中间区域规则

中间栏按状态切换：

- `charging == true`
  - 显示充电状态图形
  - 不显示时间
- `full == true`
  - 显示满电状态图形
- 未充电
  - 显示内置图片资源

当前图片资源已经转成编译期数组，直接随固件编译，不依赖文件系统。

## 8. 电源行为

屏幕模块会响应 CAF 电源事件：

- 收到 `power_down_event`
  - 关闭背光
  - 打开 blanking
- 收到 `wake_up_event`
  - 重新刷新界面
  - 恢复背光
