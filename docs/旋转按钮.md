# 旋转按钮

## 1. 方案

当前旋钮模块基于 Zephyr 官方 `gpio-qdec` 驱动实现。

- 驱动：`gpio-qdec`
- 事件类型：`INPUT_EV_REL`
- 事件轴：`INPUT_REL_WHEEL`
- A/B 相：`P0.10` / `P1.06`
- 输入配置：`GPIO_PULL_UP | GPIO_ACTIVE_HIGH`

## 2. DTS 配置

板级 DTS 在 [Bluetooth_keyboard.dts](</D:/code/SGGProject/Bluetooth_keyboard/boards/cc/Bluetooth_keyboard/Bluetooth_keyboard.dts:1>) 中启用了 `gpio-qdec`：

- `steps-per-period = <2>;`
- `zephyr,axis = <INPUT_REL_WHEEL>;`
- `sample-time-us = <2000>;`
- `idle-poll-time-us = <2000>;`
- `idle-timeout-ms = <200>;`

同时因为 `P0.10` 是 NFC 复用脚，已加入：

```dts
&uicr {
	nfct-pins-as-gpios;
};
```

## 3. 应用层行为

应用层在 [src/rotary.c](</D:/code/SGGProject/Bluetooth_keyboard/src/rotary.c:1>) 里监听 `input` 事件：

- `INPUT_EV_REL`
- `INPUT_REL_WHEEL`

判定规则：

- `value > 0` 视为 `clockwise`
- `value < 0` 视为 `counterclockwise`

每次旋转打印：

- 方向
- 步数
- 累计角度

示例：

```text
rotary clockwise steps=1 total_angle=12度 value=1
rotary counterclockwise steps=1 total_angle=0度 value=-1
```

## 4. 低功耗联动

旋钮模块复用了 CAF 低功耗逻辑：

- 正常状态旋转时发送 `keep_alive_event`
- 低功耗状态旋转时发送 `wake_up_event`

低功耗状态由 `power_down_event / wake_up_event` 同步维护。

## 6. 验证

烧录后 RTT 预期先看到：

```text
rotary gpio-qdec ready: A=P0.10 B=P1.06 steps-per-period=2 sample=2000us idle-poll=2000us idle-timeout=200ms axis=INPUT_REL_WHEEL
keyboard app ready
```

旋转时预期看到：

```text
rotary clockwise steps=1 total_angle=12度 value=1
```

或：

```text
rotary counterclockwise steps=1 total_angle=-12度 value=-1
```
