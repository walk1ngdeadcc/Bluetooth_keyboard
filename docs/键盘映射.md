# 键盘映射

## 1. 当前方案

当前矩阵键盘模块已接入 `CAF button_event`，并增加了一张独立逻辑键名映射表。

数据流：

- 矩阵扫描
- `row/col -> key_id`
- `key_id -> 逻辑键名`
- 提交 `button_event`
- RTT 打印按下/松开、`key_id`、逻辑键名

## 2. key_id 规则

按你当前最终布局显式编号：

```text
X  X  X  0
1  2  3  4
5  6  7  X
8  9  10 11
12 13 14 X
15 16 X 17
```

说明：

- `X` 表示该位置无效，不会上报按键事件
- 只有 `0~18` 会作为有效 `key_id`

## 3. 当前逻辑键名表

### key_id -> 逻辑键名

- `0 -> VOLUME_MUTE`
- `1 -> NUM_LOCK`
- `2 -> KP_SLASH`
- `3 -> KP_ASTERISK`
- `4 -> KP_MINUS`
- `5 -> KP_7`
- `6 -> KP_8`
- `7 -> KP_9`
- `8 -> KP_4`
- `9 -> KP_5`
- `10 -> KP_6`
- `11 -> KP_PLUS`
- `12 -> KP_1`
- `13 -> KP_2`
- `14 -> KP_3`
- `15 -> KP_0`
- `16 -> KP_0`
- `17 -> KP_DOT`
- `18 -> KP_ENTER`

说明：

- `row1 ~ row5` 按标准数字键盘风格排布
- `KP_0 / KP_ENTER / KP_PLUS` 这种大键在矩阵里先按常见数字键盘逻辑做了重复映射
- 如果后续你要改成别的布局，只需要改 [src/keymap.c](</D:/code/SGGProject/Bluetooth_keyboard/src/keymap.c:1>)

## 4. 日志格式

按键变化时 RTT 预期：

```text
matrix key down: id=0 name=VOLUME_MUTE row=0 col=0
matrix key up: id=0 name=VOLUME_MUTE row=0 col=0
matrix key down: id=9 name=KP_8 row=2 col=1
```
